# Replai Product Overview

## Purpose

Replai is a **multi-platform AI-powered messaging automation platform** for small businesses. It provides automated customer reply capabilities across multiple communication channels.

## Target Customers

- **Small businesses** (retail shops, barber shops, service providers)
- **Target markets**: Primarily Kyrgyzstan (Russian and Kyrgyz languages)
- Businesses that need to handle customer inquiries 24/7 without dedicated support staff

## Core Functionality

### Messaging Platforms
1. **Instagram** - Direct messages and comments
2. **Telegram** - Bot-based messaging
3. **WhatsApp** - Business messaging via Twilio and Meta Cloud API

### AI Features
- **Automated responses** to customer inquiries
- **Context-aware conversations** using conversation history
- **Business profile learning** from social media profiles
- **Multi-language support** (English, Russian, Kyrgyz)
- **Custom training** with business-specific information

### Admin Capabilities
- **Business management** dashboard
- **Multi-business support** for platform administrators
- **Platform connection management**
- **Analytics and insights**
- **Business hours configuration**
- **AI personality customization**

## Business Model

### Plans
- **Free Plan**: Basic features with limitations
- **Pro Plan**: Full feature access, higher message limits

### Current Status
- **In Production**: Deployed on Render
- **Active Development**: Instagram OAuth improvements, UI optimizations
- **Database**: PostgreSQL (production), SQLite (local development)

## Product Priorities

1. **Platform Stability**: Reliable message delivery and OAuth flows
2. **Instagram Integration**: Completing Business OAuth implementation
3. **UI/UX Polish**: Admin dashboard optimization
4. **Multi-language Support**: Expanding language capabilities
5. **AI Training**: Enhanced business profile learning
