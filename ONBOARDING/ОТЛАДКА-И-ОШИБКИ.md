# 🐛 Отладка и Частые Ошибки

## Ошибка: "Cannot read property 'XXX' of undefined"

### Что это значит?
Вы пытаетесь получить свойство объекта который не существует.

### Пример:
```javascript
const user = undefined;
console.log(user.name); // ❌ Ошибка: Cannot read property 'name' of undefined
```

### Решение:
1. Добавьте `console.log()` перед строкой с ошибкой
2. Проверьте что объект существует
3. Используйте `?.` оператор (optional chaining)

```javascript
// ❌ Неправильно
const name = user.name;

// ✅ Правильно
const name = user?.name || 'Неизвестно';
```

## Ошибка: "Authorization required" или 401

### Что это значит?
Вы забыли отправить токен или он неправильный.

### Решение:
- Проверьте что добавили `Authorization` header
- Проверьте что токен правильный
- Проверьте что функция `requireBusinessAuth` в API

```javascript
// ❌ Неправильно (нет токена)
const response = await fetch('/api/business/customers');

// ✅ Правильно (с токеном)
const response = await fetch('/api/business/customers', {
  headers: {
    'Authorization': 'Bearer ' + token
  }
});
```

## Ошибка: "Cannot GET /api/business/XXX"

### Что это значит?
API endpoint не существует (неправильный путь или не добавлен в server-new.js).

### Решение:
1. Проверьте имя endpoint (точно совпадает?)
2. Проверьте что код добавлен в server-new.js около строки 4100
3. Перезапустите сервер (Ctrl+C, потом `node server-new.js`)
4. Проверьте в консоле нет ошибок при запуске сервера

## Ошибка: "Unexpected token < in JSON at position 0"

### Что это значит?
Сервер вернул HTML вместо JSON (обычно ошибка 404 или 500).

### Решение:
1. Откройте DevTools (F12)
2. Перейдите в Network tab
3. Кликните на запрос
4. Смотрите Response - там должен быть JSON, а не HTML
5. Проверьте статус (200 = успех, 500 = ошибка сервера)

## Ошибка: Карточки/Элементы не видны

### Что делать:
1. Откройте F12 → Elements tab
2. Найдите ваш элемент
3. Проверьте что он в HTML
4. Проверьте CSS (может быть `hidden` или `display: none`)
5. Проверьте что `textContent`/`innerHTML` не пустой

```javascript
// Отладка:
console.log('Элемент:', document.getElementById('statMessages'));
console.log('Текст:', document.getElementById('statMessages').textContent);
console.log('CSS:', getComputedStyle(document.getElementById('statMessages')));
```

## Ошибка: Стили не применяются

### Решение:
1. Проверьте что CSS находится в `<style>` теге или в файле `styles.css`
2. Проверьте селектор (совпадает ли с классом?)
3. Используйте `!important` если нужно переопределить

```css
/* Если не работает */
.stat-card {
  background: blue;
}

/* Попробуйте так */
.stat-card {
  background: blue !important;
}
```

## Ошибка: Поиск не работает (Dev2)

### Что делать:
1. Откройте DevTools → Network tab
2. Печатайте в поиске и смотрите какой URL отправляется
3. Проверьте что параметр передаётся: `?search=иван`
4. Тестируйте API напрямую в браузере консоли

```javascript
// Тест:
API.get('/api/business/customers?search=иван').then(console.log);
```

## Совет: Используй console.log() везде!

```javascript
async function loadCustomers(query) {
  console.log('1. Начало функции');
  console.log('2. Query:', query);

  try {
    console.log('3. Отправляю запрос...');
    const data = await API.get('/api/business/customers?search=' + query);
    console.log('4. Получил ответ:', data);

    displayCustomers(data.customers);
    console.log('5. Отобразил результаты');
  } catch (error) {
    console.error('❌ ОШИБКА:', error);
  }
}
```

**Если произойдёт ошибка - вы узнаете на каком шаге!**
