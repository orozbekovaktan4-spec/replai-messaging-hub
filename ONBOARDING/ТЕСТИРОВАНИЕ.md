# 🧪 Руководство по Тестированию

## Способ 1: Postman (Графический)

### Установка:
1. Скачайте: https://www.postman.com/downloads/
2. Откройте Postman
3. Создайте новый Request

### Тестирование Dev1 API:

```
GET http://localhost:3000/api/business/dashboard/stats

Headers:
- Authorization: Bearer [ВАШЕ_ТОКЕН]
- Content-Type: application/json
```

**Как получить токен:**
1. Откройте http://localhost:3000/business
2. Нажмите F12 → Console
3. Напечатайте: `localStorage.getItem('businessToken')`
4. Скопируйте результат (без кавычек)

**Ожидаемый результат:**

```json
{
  "success": true,
  "stats": {
    "messagesToday": 45,
    "aiResponded": 38,
    "ownerResponded": 7,
    "newCustomersToday": 3
  }
}
```

### Тестирование Dev2 API:

**Без поиска:**
```
GET http://localhost:3000/api/business/customers

Headers:
- Authorization: Bearer [ВАШЕ_ТОКЕН]
```

**С поиском:**
```
GET http://localhost:3000/api/business/customers?search=иван

Headers:
- Authorization: Bearer [ВАШЕ_ТОКЕН]
```

**Ожидаемый результат:**

```json
{
  "success": true,
  "customers": [
    {
      "id": "customer_123",
      "name": "Иван Петров",
      "phone": "+996555123456",
      "platform": "whatsapp",
      "lastMessage": "Привет! Хочу записаться...",
      "lastMessageTime": "2026-09-22T14:30:00Z",
      "totalMessages": 8
    }
  ]
}
```

## Способ 2: curl (Терминал)

### Dev1 Тестирование:
```bash
curl -X GET http://localhost:3000/api/business/dashboard/stats \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json"
```

### Dev2 Тестирование:
```bash
curl -X GET "http://localhost:3000/api/business/customers?search=иван" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## DevTools (Отладка)

### Вкладка Console (F12):
- Показывает все JavaScript ошибки
- Выводит `console.log()` сообщения
- Можно писать код и тестировать

### Вкладка Network:
1. Откройте Network tab (F12)
2. Обновите страницу (Ctrl+R)
3. Кликните на запрос (обычно XHR запросы)
4. Смотрите:
   - **Request** - что отправили
   - **Response** - что получили
   - **Status** - 200 = успех, 401 = нет авторизации, 500 = ошибка сервера

### Вкладка Elements:
1. Откройте Elements tab
2. Найдите ваш элемент
3. Смотрите HTML и CSS
4. Можно менять CSS прямо здесь для тестирования
