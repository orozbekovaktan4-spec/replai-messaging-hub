## 🔌 API Endpoints

### Dev1 (Статистика):
```javascript
GET /api/business/dashboard/stats
// Возвращает: { messagesToday, aiResponded, ownerResponded, newCustomersToday }
```

### Dev2 (Клиенты):
```javascript
GET /api/business/customers
// Возвращает: массив клиентов

GET /api/business/customers?search=иван
// Возвращает: только клиентов в имени которых "иван"
```

## 🗄️ Структура businesses.json

```json
{
  "conversations": [
    {
      "customerId": "123",
      "customerName": "Иван",
      "customerPhone": "+996555123456",
      "platform": "whatsapp",
      "messages": [
        {
          "from": "customer",
          "text": "Привет!",
          "timestamp": "2026-09-22T10:00:00Z",
          "respondedBy": null
        },
        {
          "from": "business",
          "text": "Привет! Чем помочь?",
          "timestamp": "2026-09-22T10:01:00Z",
          "respondedBy": "ai"
        }
      ]
    }
  ]
}
```

**Главные Поля:**
- `conversations[0].customerId` - ID клиента
- `conversations[0].messages` - все сообщения в диалоге
- `msg.from` - "customer" или "business"
- `msg.respondedBy` - "ai" или "owner" или null
- `msg.timestamp` - дата-время ISO формате

## 🔐 Как Работает Авторизация

```
1. Пользователь логинится (aziz@barber.com / barber123)
   ↓
2. Сервер создаёт токен
   ↓
3. Фронтенд сохраняет токен в localStorage
   ↓
4. Каждый API запрос отправляет токен в headers
   ↓
5. Сервер проверяет токен (requireBusinessAuth)
   ↓
6. Если валиден - выполняет запрос
   ↓
7. Если невалиден - возвращает 401 Unauthorized
```

## 🔍 Как Найти Ошибку

1. Откройте **DevTools:** F12
2. Смотрите **Console:** красные сообщения = ошибки
3. Смотрите **Network:** запросы и ответы
4. Смотрите **Elements:** HTML структура
5. Добавьте **console.log():** выводит значения переменных

```javascript
// Типичный отладочный код:
console.log('1. Начало');
console.log('2. Данные:', data);
console.log('3. Тип:', typeof data);
console.log('4. Конец');
```
