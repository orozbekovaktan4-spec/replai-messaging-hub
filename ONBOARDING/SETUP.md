# ⚙️ Настройка Окружения (Общее для Всех)

## Шаг 1: Клонировать Репозиторий

```bash
git clone [ссылка на репозиторий]
cd replai
```

## Шаг 2: Установить Зависимости

```bash
npm install
```

## Шаг 3: Получить .env Файл

Попросите у Актана файл `.env` с секретными ключами и положите его в корень папки:
```
replai/
├── .env          ← вставьте сюда
├── server-new.js
├── businesses.json
└── ...
```

## Шаг 4: Запустить Сервер

```bash
node server-new.js
```

Если всё работает, вы увидите:
```
✅ Server running at: http://localhost:3000
```

## Шаг 5: Проверить Что Работает

1. Откройте: http://localhost:3000/business
2. Войдите: `aziz@barber.com` / `barber123`
3. Должна открыться страница dashboard для Азиза ✅

## Шаг 6: Основные Файлы

- `server-new.js` - Backend (вы будете добавлять API сюда)
- `businesses.json` - Данные хранятся здесь
- `business-dashboard/` - Папка с frontend для Азиза
  - `dashboard.html` - Главная страница (Dev1 добавит сюда карточки)
  - `messages.html` - Страница сообщений
  - `customers.html` - НОВАЯ СТРАНИЦА (Dev2 создаст)
  - `app.js` - Общий код
  - `styles.css` - Общие стили
