## 🧪 Как Тестировать API

### Вариант 1: Postman
1. Скачай Postman: https://www.postman.com/downloads/
2. Создай новый Request
3. Выбери метод (GET/POST/etc)
4. URL: `http://localhost:3000/api/business/...`
5. Headers → Authorization: `Bearer [ТУТ_ТОКЕН]`
6. Send!

### Вариант 2: curl (в терминале)
```bash
# Получить токен (открой browser console на /business странице)
# localStorage.getItem('businessToken')

# Тестируй API
curl http://localhost:3000/api/business/customers \
  -H "Authorization: Bearer [ТВОЙ_ТОКЕН]"
```

### Вариант 3: Браузер Console (F12)
```javascript
// Открой http://localhost:3000/business
// Нажми F12 → Console
// Напечатай:

API.get('/api/business/customers').then(console.log)
```

## 🐛 Частые Проблемы

### Проблема: "Port 3000 already in use"
**Решение**:
```bash
# Найти процесс на порту 3000
lsof -i :3000

# Убить процесс
kill -9 [PID]

# Или просто перезапусти терминал
```

### Проблема: "Cannot find module"
**Решение**:
```bash
npm install
```

### Проблема: "Authorization required"
**Решение**: Ты забыл добавить токен в Headers. Смотри раздел "Как Тестировать API"

### Проблема: Изменения не отображаются
**Решение**: 
1. Остановить сервер (Ctrl+C)
2. Перезапустить: `node server-new.js`
3. Обновить страницу в браузере (Ctrl+Shift+R - жёсткая перезагрузка)
