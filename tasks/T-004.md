### 3. Bridge Architecture Options (15 minutes)

**If direct access isn't available, what bridge architectures are possible?**

**Option A: PTY Interaction**
- Kiro Manager spawns bridge process
- Bridge attaches to Claude Code's PTY
- Bridge forwards input/output
- Requirements: PTY access, process permissions

**Option B: Terminal Multiplexer Bridge**
- Claude Code runs in tmux/screen session
- Kiro Manager sends commands via tmux/screen CLI
- Output captured from session
- Requirements: tmux/screen installed, session management

**Option C: MCP Server Bridge**
- Custom MCP server with terminal interaction capabilities
- Server manages communication with Claude Code terminal
- Kiro Manager calls MCP server tools
- Requirements: MCP server development, terminal access

**Option D: File-Based Communication**
- Kiro Manager writes to shared file
- Claude Code monitors file for new requests
- Claude Code writes responses to output file
- Kiro Manager monitors output file
- Requirements: File watching, Claude Code cooperation

**Option E: Named Pipes (FIFO)**
- Create named pipes for bidirectional communication
- Kiro writes to input pipe
- Claude reads from input pipe, writes to output pipe
- Kiro reads from output pipe
- Requirements: UNIX pipes, process coordination

**For each option, document**:
- Architecture diagram
- Required components
- Implementation complexity
- Latency characteristics
- Reliability concerns
- Security implications

## What to Investigate

### Terminal Process Discovery

**Try to identify Claude Code terminal process:**

```bash
# Check running processes (if safe to run)
ps aux | grep -i "claude"
ps aux | grep -i "kiro"

# Check if Claude Code is a known binary
which claude-code
which claude

# Look for terminal configuration
cat ~/.kiro/settings/*.json | grep -i terminal
cat ~/.kiro/settings/*.json | grep -i claude

# Check for MCP servers that might handle terminal
cat .kiro/settings/mcp.json
```

**IMPORTANT**: Only run safe read-only commands. Do NOT:
- Kill processes
- Modify configurations
- Start new processes
- Interfere with running terminal
