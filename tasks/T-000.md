# T-000: Verify Agent Workflow Setup

## Goal

Verify that the new agent workflow infrastructure operates correctly by completing a simple documentation task.

## Files and Context

- `docs/` - Documentation directory
- `reports/` - Reports directory
- `AGENT_PROTOCOL.md` - Workflow rules to follow
- `CLAUDE.md` - Your Builder instructions

## What to Do

1. Read `AGENT_PROTOCOL.md` to understand the workflow rules
2. Read `CLAUDE.md` to understand your role as Builder
3. Create a new file: `docs/hello.md`
4. Add the exact text `agent setup ok` as the first line
5. Add the current date on a separate line (format: Month DD, YYYY)
6. Follow the agent protocol:
   - Check git status before and after changes
   - Only modify the specified file
   - Write a completion report
   - Make a clean commit
7. Write your completion report to `reports/T-000.md`

## What NOT to Do

- Do not modify application code (`.js` or `.html` files)
- Do not modify existing documentation files
- Do not modify environment variables or `.env` files
- Do not delete any files
- Do not make changes unrelated to this task

## Acceptance Criteria

- [ ] File `docs/hello.md` exists
- [ ] It contains the text `agent setup ok` on the first line
- [ ] It contains the current date on the second line
- [ ] Report `reports/T-000.md` exists
- [ ] Report accurately describes the work performed
- [ ] Report includes testing/verification steps
- [ ] Git commit follows format: `T-000: description`
- [ ] Only `docs/hello.md` and `reports/T-000.md` are in the commit
