## Context

The CEO wants to enable direct communication with Claude Code (Builder) through Kiro (Manager) as an intermediary.

**Desired Flow**:
```
CEO → Kiro → Claude Code (Builder) → Kiro → CEO
```

**Example Scenario**:
1. CEO asks Kiro: "Claude, explain how our Instagram OAuth works."
2. Kiro forwards question to active Claude Code Builder session
3. Claude Code investigates and responds
4. Kiro displays Claude's actual response (attributed to Claude Code)
5. CEO can continue conversation with same Builder session
6. Builder maintains context across messages

**Critical Requirements**:
- Kiro must NOT invent or rewrite Claude's responses
- Responses must be clearly attributed to Claude Code
- Session persistence for multi-turn conversations
- Visibility into Claude's actual technical work
