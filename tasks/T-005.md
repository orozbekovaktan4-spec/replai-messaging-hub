## Implementation Details

### 1. Setup Script (`scripts/claude-screen-setup.sh`)

**Purpose**: Start Claude Code in screen session with proper configuration

**Requirements**:
- Kill any existing `claude-code-main` session
- Set required environment variables:
  ```bash
  export CLAUDE_CONFIG_DIR="$HOME/.claude-omniroute"
  export ANTHROPIC_BASE_URL="http://localhost:20128"
  export ANTHROPIC_AUTH_TOKEN="sk-94fb88271530e36c-9c929f-7ee0bd79"
  export ANTHROPIC_API_KEY=""
  export ANTHROPIC_MODEL="aktan"
  ```
- Start screen session with name `claude-code-main`
- Launch `claude` inside session
- Verify session is running

**Script Structure**:
```bash
#!/bin/bash
# scripts/claude-screen-setup.sh

set -e

SESSION_NAME="claude-code-main"

echo "[Setup] Checking for existing session..."
if screen -list | grep -q "$SESSION_NAME"; then
    echo "[Setup] Killing existing session..."
    screen -S "$SESSION_NAME" -X quit 2>/dev/null || true
fi

echo "[Setup] Starting new Claude Code screen session..."
screen -dmS "$SESSION_NAME" bash -c '
export CLAUDE_CONFIG_DIR="$HOME/.claude-omniroute"
export ANTHROPIC_BASE_URL="http://localhost:20128"
export ANTHROPIC_AUTH_TOKEN="sk-94fb88271530e36c-9c929f-7ee0bd79"
export ANTHROPIC_API_KEY=""
export ANTHROPIC_MODEL="aktan"
cd /Users/ak/replai
claude
'

sleep 2

if screen -list | grep -q "$SESSION_NAME"; then
    echo "[Setup] ✓ Claude Code session started successfully"
    echo "[Setup] Attach with: screen -r $SESSION_NAME"
    echo "[Setup] Detach with: Ctrl+A then D"
else
    echo "[Setup] ✗ Failed to start session"
    exit 1
fi
```

**Make executable**:
```bash
chmod +x scripts/claude-screen-setup.sh
```

### 2. Bridge Script (`scripts/claude-bridge.sh`)

**Purpose**: Send prompts to Claude and capture responses

**Parameters**:
- `$1` - Prompt text to send to Claude

**Requirements**:
- Check session exists
- Send prompt with proper Enter key
- Wait for response (configurable timeout)
- Capture output
- Clean/format output
- Return to stdout

**Script Structure**:
```bash
#!/bin/bash
# scripts/claude-bridge.sh

set -e

SESSION_NAME="claude-code-main"
TIMEOUT=${2:-5}  # Default 5 second timeout
OUTPUT_FILE="/tmp/claude-bridge-output-$$.txt"

# Validate arguments
if [ -z "$1" ]; then
    echo "Usage: $0 <prompt> [timeout_seconds]"
    exit 1
fi

PROMPT="$1"

# Check session exists
if ! screen -list | grep -q "$SESSION_NAME"; then
    echo "Error: Claude Code screen session not found"
    echo "Run: ./scripts/claude-screen-setup.sh"
    exit 1
fi

# Send prompt to screen session
echo "[Bridge] Sending prompt to Claude..."
screen -S "$SESSION_NAME" -X stuff "$PROMPT"$'\015'

# Wait for response
echo "[Bridge] Waiting ${TIMEOUT}s for response..."
sleep "$TIMEOUT"

# Capture output
screen -S "$SESSION_NAME" -X hardcopy "$OUTPUT_FILE"

# Check if output was captured
if [ ! -f "$OUTPUT_FILE" ]; then
    echo "Error: Failed to capture output"
    exit 1
fi

# Display captured output (last 50 lines to show recent interaction)
echo "[Bridge] ========== Claude Code Response =========="
tail -50 "$OUTPUT_FILE"
echo "[Bridge] ==========================================="

# Cleanup
rm -f "$OUTPUT_FILE"
```

**Make executable**:
```bash
chmod +x scripts/claude-bridge.sh
```
