## Добро пожаловать в команду REPLAI! 🎉

Вы присоединяетесь к REPLAI - AI-платформе для управления сообщениями, которая помогает бизнесам в Бишкеке управлять WhatsApp, Instagram и Telegram из одного места.

## 📚 Фаза 1: Понимание Проекта (День 1)

### Что такое REPLAI?
- **Проблема**: Бизнесы получают сообщения из WhatsApp, Instagram, Telegram - сложно управлять всем
- **Решение**: Один dashboard для всех сообщений + AI отвечает автоматически
- **Пример клиента**: Азиз (владелец барбершопа) получает заказы через Instagram DM - AI отвечает мгновенно

### Прочитайте эти файлы (30 минут):

2. `HOW-AI-RESPONSES-WORK.md` - Как AI генерирует ответы
3. `CONNECTION-ARCHITECTURE.md` - Как подключаются платформы

### Ключевые технологии которые мы используем:
- **Backend**: Node.js + Express
- **Frontend**: Vanilla HTML/CSS/JS (без фреймворков - всё просто!)
- **AI**: Groq API (бесплатный, быстрый)
- **APIs**: Meta Graph API (WhatsApp + Instagram), Telegram Bot API
- **Хранилище**: JSON файлы (businesses.json, sessions.json)
