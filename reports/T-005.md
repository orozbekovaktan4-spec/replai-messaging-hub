## Technical Implementation

### Key Discovery
The working method from user testing was validated:
```bash
screen -S claude-main -X stuff "prompt"$'\015'
sleep 4
screen -S claude-main -X hardcopy /tmp/output.txt
tail -30 /tmp/output.txt
```

This uses `$'\015'` (carriage return) instead of `\n` to properly send Enter to the screen session.

### Session Configuration
```bash
screen -dmS "claude-code-main" bash -c "
    export CLAUDE_CONFIG_DIR=\"\$HOME/.claude-omniroute\"
    export ANTHROPIC_BASE_URL=\"http://localhost:20128\"
    export ANTHROPIC_AUTH_TOKEN=\"sk-94fb88271530e36c-9c929f-7ee0bd79\"
    export ANTHROPIC_API_KEY=\"\"
    export ANTHROPIC_MODEL=\"aktan\"
    claude
"
```

### Output Capture
- Location: `/tmp/claude-output.txt`
- Method: `screen -X hardcopy`
- Display: Last 30 lines (configurable)
